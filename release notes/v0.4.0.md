## What's New in v0.4.0

### ✨ New Features

**Advanced Agent Loop Settings** — For power users who want fine-grained control over how their AI model behaves. A new Agent Loop tab in Settings (hidden behind a toggle on the General page) lets you customize the exact prompts, tool descriptions, safety rule descriptions, chart guidance, and error recovery messages your model receives. Every field starts with a sensible default and has a one-click reset. See [AGENT_LOOP_CONFIG.md](documentation/AGENT_LOOP_CONFIG.md) for full details.

**Discussion Defaults** — Configure default settings for new discussions in Settings → Defaults. Set your preferred LLM provider, data source, message limits, and toggle preferences (summaries, visualizations, streaming, tech details) once — new discussions pick them up automatically.

**Cancel In-Progress Messages** — A Cancel button now appears during message processing. If the LLM is stuck in an exploration loop, generating bad SQL, or taking too long, you can stop it and return the conversation to a clean state. Your message is saved and you can try again immediately.

**Model Encouraged to Add Commentary** — The AI model is now encouraged to pair natural-language analysis with query results. When data may need interpretation — trends, outliers, complex relationships — the model adds context to help you understand what the numbers mean, not just what they show. Raw table requests ("give me a table of all orders") still skip commentary as expected.

**Streaming Responses** — See the LLM's answer stream in real time as it's generated. Token usage stats are displayed per response. Enable per-conversation via the gear menu.

**PDF Export** — Export any discussion as a PDF via the native print dialog (File → Print or ⌘P).

**Accent Color Warning** — The custom accent color picker now warns you if the color is too light and may have poor contrast on light backgrounds.

### 🔧 Improvements

- **Dark mode** now applies consistently across all UI elements — settings panels, conversation view, popovers, and modals.
- **UI scale** (Small / Medium / Large) survives app refreshes and restarts.
- **About page** now shows the actual release version and includes an auto-update check button.
- Messages in LLM context now defaults to 5 (was unlimited) with a hard cap of 15 — prevents context-window exhaustion and empty responses.
- Summarization uses a compact digest (column stats + representative rows) instead of the full result set, making summaries faster and more reliable for large results.
- Exploration safety mode descriptions are now configurable (Settings → Data Sources → Edit → Exploration Settings).

### 🐛 Fixed

- API key is no longer wiped when editing an existing LLM provider's other settings.
- Database password is no longer wiped when editing an existing data source's other settings.
- "Thinking..." message no longer appears on all conversations.
- Discussion list now refreshes automatically after sending a message.
- Archived conversations show a visual indicator (accent-colored left border).
- Password field shows "(leave blank to keep current)" hint when editing existing connections.
- Null slice bug fixed — Go slices returned to Wails frontend now use `make()` instead of `var` to prevent null serialization issues.

## Installation

### macOS
Download the `.dmg`, open it, and drag `YourQL.app` into `/Applications`. Replace any existing copy. If you see a Gatekeeper warning, right-click → Open.

### Windows
Download `YourQL.exe` and run it. Replace any existing copy. An installer (`.exe`) with Start Menu shortcuts is coming in a follow-up release.

## Upgrading
Replace your current binary with the new one. All your conversations, settings, credentials, and UI preferences are stored in `~/.yourql/yourql.db` (macOS/Linux) or `%USERPROFILE%\.yourql\yourql.db` (Windows) and survive upgrades automatically.

## New to YourQL?
YourQL is a desktop app that lets you talk to your database in plain English. Connect to MySQL, PostgreSQL, SQLite, SQL Server, Snowflake, BigQuery, Redshift, MariaDB, CSV files, Excel files, or Google Sheets — and ask questions the way you'd ask a colleague. Bring your own AI model (OpenAI, Anthropic, Ollama, or any compatible endpoint). Everything runs locally.
